# Anantapur property tax assessments and online applications

## Find the existing account

[Know Your Dues](https://anantapur.emunicipal.ap.gov.in/ptis/citizen/search/search-searchForm.action) accepts an assessment number, old assessment number, owner name or door number. The form requires at least one of those values. If you have the assessment number on the municipal record, use it to distinguish the account from other search results. The [property tax calculator](https://anantapur.emunicipal.ap.gov.in/ptis/calculatepropertytax) is a separate link, not a lookup of the amount currently due on an assessment.

## Choose the correct application

| Task | City portal form |
| --- | --- |
| Start a new property self-assessment | [Self Assessment](https://anantapur.emunicipal.ap.gov.in/ptis/create/createProperty-newForm.action?applicationSource=online) |
| Ask for a revision of an existing assessment | [Revision Petition](https://anantapur.emunicipal.ap.gov.in/ptis/search/searchproperty-revisionpetition.action?applicationSource=online) |
| Start a transfer on the municipal assessment record | [Mutation](https://anantapur.emunicipal.ap.gov.in/ptis/search/searchproperty-registeredtransfer.action?applicationSource=online) |
| Seek vacancy remission on an existing assessment | [Vacancy Remission](https://anantapur.emunicipal.ap.gov.in/ptis/search/searchproperty-vacancyremission.action?applicationSource=online) |

The revision, mutation and vacancy remission forms start with an assessment-number search. To retrieve paperwork already issued, use [Download Proceedings](https://anantapur.emunicipal.ap.gov.in/ptis/reports/citizen-searchnotices.action) with an assessment number or application number. These are form entry points; filing a petition is not evidence it has been approved.

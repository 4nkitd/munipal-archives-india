# Bhilai building permission portal

## Corporation selection

The state Building Permission Management System is labelled e-Town Planning. Its corporation selector includes Municipal Corporation Bhilai, with separate entries for Durg and Risali. Bhilai-Charoda is directed to a separate NiwasPass route. For property within Bhilai Municipal Corporation, use the Bhilai option rather than another municipality with "Bhilai" in its name.

The system describes a process in which citizens upload required documents and the application passes system checks. This archive verified the listed corporation, not a submitted application or the current availability of a particular approval. For address jurisdiction or help with the applicable channel, the [district directory](https://durg.gov.in/en/public-utility-category/municipality/) lists the Bhilai municipal office.

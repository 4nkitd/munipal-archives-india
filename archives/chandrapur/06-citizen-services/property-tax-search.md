# Chandrapur municipal property tax lookup

## Find the assessment

| Portal tab | Search detail |
|---|---|
| Find By Property Number | Enter the ward number and property number in their separate fields. |
| Find By Name | Use the name search when locating the assessment by the name on record. |
| Find By UPIC ID | Use the property’s UPIC identifier. |

The ward field belongs to the property assessment search. Use the ward reference on the municipal property record: the State Election Commission's count of electoral wards is not a lookup table for tax assessments. The page identifies dues checking and receipt download as property-tax services. For an application under the Right to Service Act, it links separately to the municipal RTS portal.

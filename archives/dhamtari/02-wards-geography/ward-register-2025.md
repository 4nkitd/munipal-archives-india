# Dhamtari ward numbers in the 2025 councillor return

## Finding the corporation in the statewide return

Serial entries 2009 to 2048 cover Dhamtari. The serial number identifies a row in the statewide publication; the ward number starts again at 1 for this corporation and runs through 40. The [City Finance register](https://www.cityfinance.in/api/v1/ulb) identifies the same body by LGD code 248062, Census code 802052 and a 2011 Census population of 89,860.

# Dhamtari mayoral election result, 2025

## Corporation-wide vote

The commission marks Ramu Rohra of the Bharatiya Janata Party as elected for Dhamtari Municipal Corporation. The return lists 8 candidates and a separate entry for none of the above (NOTA).

| Result | Votes |
| --- | ---: |
| Elected candidate | 38,655 |
| Next-highest candidate | 4,580 |
| Difference | 34,075 |
| NOTA | 1,789 |

The difference is calculated from the two candidate totals. For a councillor result, use the separate ward return in the [2025 election catalogue](https://cgsec.gov.in/hin_2025chunavnagarpalika.html).

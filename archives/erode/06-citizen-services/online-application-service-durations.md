# Erode citizen portal application service durations

## What the application report shows

The corporation links the one-page "Service Time Duration" report from its [Citizen Charter page](https://www.tnurbantree.tn.gov.in/erode/citizen-charter/). It bears a print date of **27 August 2023** and is filtered to **ServiceMode: Citizen Portal** and **ServiceType: Application**. The report's column is labelled "Duration" and does not state a unit. These numbers reproduce that column; they are not independently verified turnaround times.

| Application | Duration as printed |
| --- | ---: |
| Child name registration | 3 |
| Building licence request | 15 |
| New profession tax assessment | 15 |
| New property assessment | 30 |
| Road cutting permission | 7 |
| New trade licence or renewal | 3 |
| New underground drainage connection | 15 |
| New water supply connection | 30 |
| Water connection name transfer | 15 |

## Check the applicable channel

The charter's HTML page separately describes counter services and complaint handling. For example, it describes acknowledging a completed water-connection application immediately at the information centre and providing the connection within 30 days of the completed form. The portal report and the charter page cover different steps and channels. Check the [state municipal payment and services portal](https://tnurbanepay.tn.gov.in/) and the corporation's current instructions before applying.

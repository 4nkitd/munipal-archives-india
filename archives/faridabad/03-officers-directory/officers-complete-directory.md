# Municipal Corporation Faridabad officers directory

## Commissioner's office

The [district administrative directory](https://faridabad.nic.in/department/administrative-officers/) lists **Sh. Yashendra Singh, IAS**, Commissioner, Municipal Corporation Faridabad, at **0129-2416464**, MCF Office, near B.K. Chowk, Faridabad. This is the municipal office, distinct from the Commissioner of Faridabad Division. For a present-day branch contact, confirm the posting with the municipal office.

The date above is the compilation date. The [former Haryana ULB officers directory](https://www.ulbharyana.gov.in/Faridabad/404) survives in the search index with a footer dated 20 May 2025, but the page now returns a not-found message. It listed A. Mona Sreenivas as Commissioner and `cmc-faridabad@ulbharyana.gov.in` as the office mailbox. The following branch tables preserve published assignments, not a single list of incumbents as of November 2026.

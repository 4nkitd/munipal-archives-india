# Slow-moving vehicle licences in Guwahati

## Applying at the SMV branch

Owners and pullers both need a licence, valid for one year. The GMC guide directs applicants to the SMV branch at Lakhtokia, Guwahati 781001, and lists two application forms in Assamese. An owner supplies address proof. A puller supplies a police report, a Gaon Burha certificate and a voter ID card.

| Application | Fee in the guide |
| --- | ---: |
| Rickshaw owner | ₹100 |
| Thela (handcart) owner | ₹200 |
| Ice-cream cart or van owner | ₹130 |
| Puller, first licence | No fee |

For renewal, submit the old licence to the SMV office; the guide lists ₹100 for renewal. For a duplicate, address an application to the deputy commissioner of the relevant zone. The listed duplicate fee is ₹15.

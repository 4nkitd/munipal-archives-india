# Gwalior municipal ward population in Census 2011

## Corporation rows

In the district's Primary Census Abstract workbook, town code `802100` has a `Gwalior (M Corp.)` town row and numbered ward rows 1 through 60. The ward rows sum to the published town totals, 199,466 households and 1,054,420 people. The table below includes the first and last wards and the wards with the lowest and highest population.

| Census ward | Households | Population |
| ---: | ---: | ---: |
| 1 | 3,499 | 19,913 |
| 18 | 8,611 | 39,833 |
| 59 | 1,500 | 9,138 |
| 60 | 4,501 | 24,278 |

The catalogue entry was created on 19 January 2021, but the data refer to Census 2011 geography. The local body's separate [City Finance return](https://www.cityfinance.in/api/v1/ulb) gives 66 wards for LGD code `250694`. Neither source establishes the current boundaries of an individual ward.

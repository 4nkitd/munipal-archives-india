# Hubballi-Dharwad property tax search and payment

## Find an assessment before paying

The [corporation homepage](http://www.hdmc.mrc.gov.in/en/home) links to a separate online property tax payment site. Its search form offers three modes: **Search by Criteria**, **Search by NewPId** and **Search by OldPId**. If the property ID is unknown, the page instructs users to enter the ward number with either the old assessment number or the new assessment number and then search for the property details.

The payment homepage links separately to **New Property Registration**. That is not the existing tax account search. The payment homepage also displays rebate messages with different April deadlines in 2024 and 2025. Neither message establishes a rebate for the current year. Verification covered the publicly displayed search form, not a live assessment or payment.

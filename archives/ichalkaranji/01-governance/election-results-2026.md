# Final results of the January 2026 corporation election

## Extent and seat totals

Row 28 of the State Election Commission's final party-wise return covers Ichalkaranji Municipal Corporation. It records 16 electoral wards, 65 seats, 230 contesting candidates and results declared for all 65 seats. Wards and seats are different counts because Ichalkaranji uses multi-member wards.

| Party or commission reporting category | Seats |
| --- | ---: |
| Bharatiya Janata Party | 43 |
| Nationalist Congress Party | 1 |
| Shiv Sena | 3 |
| Shiv Sena (Uddhav Balasaheb Thackeray) | 1 |
| Unrecognised parties registered with the State Election Commission | 17 |
| Total | 65 |

All other categories in the commission row, including independents, have zero seats. The [municipal election index](https://ichalkaranjimnp.in/general-election-2025/) links to the corporation's final local result for seat-level detail. The statewide return is an aggregate, not a current councillor directory.

# Indore municipal wards in the 2011 Primary Census Abstract

## Edition and coverage

Census table `PC11_PCA-TV-2322` identifies Indore by town code `802273`. The catalog record was created on 19 January 2021; the figures refer to 2011. The [City Finance register](https://www.cityfinance.in/api/v1/ulb) separately reports 85 wards for LGD `250901`. Numbering in the census is not evidence of present electoral boundaries. Indore outgrowths have separate labels in the workbook; Tigaria Badshah (OG), for example, carries code 0076. The table below includes only rows named Indore (M Corp.).

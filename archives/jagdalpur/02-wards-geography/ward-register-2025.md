# Jagdalpur ward numbers in the 2025 councillor return

## Finding the corporation in the statewide return

Serial entries 2864 to 2911 cover Jagdalpur. The serial number identifies a row in the statewide publication; the ward number starts again at 1 for this corporation and runs through 48. The [City Finance register](https://www.cityfinance.in/api/v1/ulb) identifies the same body by LGD code 250665, Census code 802064 and a 2011 Census population of 125,463.

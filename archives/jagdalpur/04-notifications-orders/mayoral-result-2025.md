# Jagdalpur mayoral election result, 2025

## Corporation-wide vote

The commission marks Sanjay Pandey of the Bharatiya Janata Party as elected for Jagdalpur Municipal Corporation. The return lists 5 candidates and a separate entry for none of the above (NOTA).

| Result | Votes |
| --- | ---: |
| Elected candidate | 38,038 |
| Next-highest candidate | 29,276 |
| Difference | 8,762 |
| NOTA | 615 |

The difference is calculated from the two candidate totals. For a councillor result, use the separate ward return in the [2025 election catalogue](https://cgsec.gov.in/hin_2025chunavnagarpalika.html).

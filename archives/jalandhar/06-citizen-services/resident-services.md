# Where to pay Jalandhar municipal bills and track applications

The [MCJ service directory](https://mcjalandhar.in/citizen-e-services.html) distinguishes payment of an existing water and sewerage bill from an application for a new connection. Select the service that matches the task:

| Task | Official route listed by MCJ |
| --- | --- |
| Pay municipal property tax | [Punjab mSeva](https://mseva.lgpunjab.gov.in/) |
| Pay a water or sewerage bill | [MCJ payment service](https://mcjalandhar.org/Pay/Pay.aspx) |
| Apply for a new water or sewage connection | MCJ lists this separately but provides no destination link. Its general helpline is 0181 224 2411. |
| Submit a building plan | [Punjab e-Naksha](https://enaksha.lgpunjab.gov.in/) |
| Track a birth or death application | [Punjab eSewa](https://esewa.punjab.gov.in/) |
| Seek a fire no-objection certificate | [Punjab Fire NOC](https://firenoc.lgpunjab.gov.in/) |
| Lodge a grievance | [Punjab Connect](https://connect.punjab.gov.in/) or the mSeva PGRS complaints entry |

MCJ’s [contact page](https://mcjalandhar.in/contact-us.html) lists 9056531709 specifically for property-tax WhatsApp enquiries.

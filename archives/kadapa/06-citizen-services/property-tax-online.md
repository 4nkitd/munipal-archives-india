# Kadapa property tax dues, mutation and proceedings lookup

## Find the assessment before opening an application

The Kadapa city portal sends taxpayers to the Kadapa instance of eMunicipal. [Know Your Dues](https://kadapa.emunicipal.ap.gov.in/ptis/citizen/search/search-searchForm.action) asks for at least one of four inputs: assessment number, old assessment number, owner name or door number. A broad lookup helps when you only have a door number or an old record. The separate service forms for changes to an existing record use the assessment number.

| Task | Form |
| --- | --- |
| Start a municipal ownership transfer | [Mutation](https://kadapa.emunicipal.ap.gov.in/ptis/search/searchproperty-registeredtransfer.action?applicationSource=online) |
| Apply to revise an assessment | [Revision Petition](https://kadapa.emunicipal.ap.gov.in/ptis/search/searchproperty-revisionpetition.action?applicationSource=online) |
| Apply for vacancy remission | [Vacancy Remission](https://kadapa.emunicipal.ap.gov.in/ptis/search/searchproperty-vacancyremission.action?applicationSource=online) |
| Start a new property assessment | [Self Assessment](https://kadapa.emunicipal.ap.gov.in/ptis/create/createProperty-newForm.action?applicationSource=online) |

## After submitting an application

[Download Proceedings](https://kadapa.emunicipal.ap.gov.in/ptis/reports/citizen-searchnotices.action) is labelled Search Notices on eMunicipal and takes an assessment number or an application number. It is for retrieving issued records. [Application Status](https://kadapa.emunicipal.ap.gov.in/wtms/elastic/appSearch/) is a separate form with a service selector and fields for application number and identifier number. A revenue assessment lookup is not a land title search. This guide records the forms, not a completed transfer, an eligibility decision or a processing deadline.

# Kannur corporation wards in the State Election Commission directory

## Which list to use

On its public [constituencies portal](https://sec.kerala.gov.in/public/cnstncy), the State Election Commission (SEC) distinguishes the Kannur district corporation entry from the district's municipal councils. The corporation table has 56 consecutive entries, from Palliyammoola (`C13006001`) to Panjikkayil (`C13006056`). The page does not give an issue date for this table. Two distinct codes, for example, identify Kakkadu at 10 and Kakkadu North at 12. Keep the suffixes when matching a ward name.

This is a name and code directory, not an election result, voter roll or boundary description. Use the SEC's [polling station directory](https://sec.kerala.gov.in/public/ps) for station information or its [electoral roll search](https://sec.kerala.gov.in/public/voters/list) to look up a roll. The [Delimitation Commission](https://delimitation.lsgkerala.gov.in/) links to final notifications for legal boundary checks. Neither the table below nor the presence of a locality name determines which ward contains a given address.

# Kolhapur municipal general election 2025-26: final seat totals

## Kolhapur result, row 18

The State Election Commission's [publication register](https://mahasec.maharashtra.gov.in/Site/ViewAllNews) dates the final party position to 16 January 2026. Kolhapur appears in row 18. Ichalkaranji has a separate return in row 28.

| Party or grouping in the return | Seats won |
|---|---:|
| Indian National Congress | 34 |
| Bharatiya Janata Party | 26 |
| Shiv Sena | 15 |
| Nationalist Congress Party | 4 |
| Shiv Sena (UBT) | 1 |
| Unrecognized parties registered with the SEC | 1 |
| Total declared | 81 |

The commission gives 20 in the ward column and 81 in the seats column, with 327 contesting candidates. Congress won the largest number of seats. The return does not identify which wards supplied its 34 councillors or name the party that won the single seat in the unrecognized-party column.

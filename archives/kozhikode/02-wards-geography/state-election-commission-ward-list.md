# Kozhikode corporation wards in the State Election Commission directory

## Which list to use

The State Election Commission (SEC) spells the local body "Kozhikkode" in its constituency directory. The corporation ward table runs from `C11005001` to `C11005076`. The corporation's older [Ward Details page](https://kozhikodecorporation.lsgkerala.gov.in/en/node/328) and [history page](https://kozhikodecorporation.lsgkerala.gov.in/en/history) show 75 wards. Numbers should be checked against the edition used: for example, the SEC has Medical College South at 19 and Medical College at 20. The SEC page does not state an issue date for the table.

Use the table below to match a ward name and code. The SEC's [electoral roll search](https://sec.kerala.gov.in/public/voters/list) and [polling station directory](https://sec.kerala.gov.in/public/ps) are separate from this ward list. For a legal boundary, follow the [Delimitation Commission's final notification entry point](https://delimitation.lsgkerala.gov.in/), not a name match against an address. The table does not transcribe voter totals or identify elected members.

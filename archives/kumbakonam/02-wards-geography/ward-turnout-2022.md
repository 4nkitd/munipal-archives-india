# Kumbakonam ward turnout in the 2022 corporation election

## Reading the district return

The Tamil Nadu State Election Commission published one corporation result book for Thanjavur district. Ward numbers restart for each corporation. Only the Kumbakonam entries are reproduced here. Adding their ward figures gives 128,540 electors, 84,006 votes cast, 84,006 valid votes and 0 invalid votes. These are electoral wards as reported for 2022; the return does not describe their boundaries.

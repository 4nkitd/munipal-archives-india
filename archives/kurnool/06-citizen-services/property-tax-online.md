# Kurnool property tax dues, assessment changes and application status

## Check whether you need a lookup or an application

[Know Your Dues](https://kurnool.emunicipal.ap.gov.in/ptis/citizen/search/search-searchForm.action) searches the corporation's existing property assessments. Enter at least one of the assessment number, old assessment number, owner name or door number. Use the [property tax calculator](https://kurnool.emunicipal.ap.gov.in/ptis/calculatepropertytax) for a calculation, not to retrieve the billed amount on an account.

| If you need to | Use |
| --- | --- |
| Submit a new assessment | [Self Assessment](https://kurnool.emunicipal.ap.gov.in/ptis/create/createProperty-newForm.action?applicationSource=online) |
| Ask for a change to the assessment | [Revision Petition](https://kurnool.emunicipal.ap.gov.in/ptis/search/searchproperty-revisionpetition.action?applicationSource=online) |
| Start a transfer of the assessment record | [Mutation](https://kurnool.emunicipal.ap.gov.in/ptis/search/searchproperty-registeredtransfer.action?applicationSource=online) |
| Apply for vacancy remission | [Vacancy Remission](https://kurnool.emunicipal.ap.gov.in/ptis/search/searchproperty-vacancyremission.action?applicationSource=online) |

The last three service forms take an assessment number at the first step. Keep the application number after filing. [Download Proceedings](https://kurnool.emunicipal.ap.gov.in/ptis/reports/citizen-searchnotices.action) searches by assessment number or application number. [Application Status](https://kurnool.emunicipal.ap.gov.in/wtms/elastic/appSearch/) has a service selector and application and identifier fields. These links apply to Kurnool Municipal Corporation, not other urban local bodies in Kurnool district.

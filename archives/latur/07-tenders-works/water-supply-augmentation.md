# Latur: records for the city water supply augmentation scheme

## Project file

The corporation lists nine records for the augmentation scheme. Their serial numbers identify which file to consult for a question about approval, design or procurement.

| Question | Index entries |
|---|---|
| What approvals are on file? | 1: Tharav (resolution); 5: GR (government resolution); 8: SLTC minutes |
| What work did the city plan? | 2: detailed project report (DPR); 3: estimate; 4: drawing |
| What did the city invite bids for or order? | 7: pre-bid document; 9: tender document; 6: work order |

The index labels the estimate and work order separately. It does not state a final expenditure or a commissioning date.

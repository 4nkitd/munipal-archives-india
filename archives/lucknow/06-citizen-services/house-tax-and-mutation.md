# Lucknow house tax lookup, payment and property mutation

## Find a property and choose the right form

| Task | Municipal page | What the page asks for or shows |
| --- | --- | --- |
| Find the House ID or check tax | [Know your house tax](https://lmc.up.nic.in/internet/searchnewhouseid.aspx) | The page lists New House Id, Old Computer Code, mobile number, house number, owner name or father's name as search fields and requires a security PIN. The location selectors include zones 1–8, ward and mohalla. |
| Pay on a registered property | [House tax and user charges login](https://lmc.up.nic.in/internet/user_loginnew.aspx) | The login page also links to House ID lookup, new user registration and password recovery. |
| Start a first assessment | [Online self-assessment](https://lmc.up.nic.in/internet/User_Login_online.aspx) | Use the First Assessment page for new assessment. The corporation tells owners of already registered houses, shops and other properties to use the login instead of self-assessment. |
| Apply for mutation or check its status | [House mutation](https://lmc.up.nic.in/internet/MutationHomePage.aspx) | This page links separately to the new request and the status search. Both ask for a mobile number, House ID and security PIN. |

The tax lookup's result fields distinguish current tax, arrears, interest and the total outstanding balance. The [municipal homepage](https://lmc.up.nic.in/) says to contact the corporation office if an online payment has not appeared on the website after **seven office working days**.

## Mutation documents

The [new mutation request](https://lmc.up.nic.in/internet/mutationrequest1.aspx) lists a proposed owner's photo and a scan of one identity document in JPEG format, each not exceeding 300 KB. It lists Voter ID, Driving License, PAN Card, Passport and Aadhaar Card as alternatives for the identity document. The page also lists an affidavit and evidence supporting the mutation. Those two rows say "PDF Only" but also display a JPEG size note. Confirm the accepted format with the corporation before uploading either document. Check a submitted request on the [mutation status page](https://lmc.up.nic.in/internet/mutationstatus.aspx).

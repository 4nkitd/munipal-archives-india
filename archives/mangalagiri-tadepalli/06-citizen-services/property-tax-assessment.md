# Find a Mangalagiri Tadepalli property tax assessment

## Use the municipal tax portal

The [AP CDMA urban local bodies directory](https://cdma.ap.gov.in/ulb-web-directory) links the Mangalagiri Tadepalli corporation to a civic site whose address uses `mangalagiri`. The [corporation home page](https://mangalagiri.cdma.ap.gov.in/ulbprofile/mangalagiri/home) links that site's **Know Your Dues** service to the municipal property tax system. The search form offers Assessment Number, Old Assessment Number, Owner Name and Door Number. Use the assessment number from a municipal notice or receipt if you have it, then check the returned property details.

This lookup is for the corporation's tax assessments. It does not search APCRDA land-pooling plots, development permissions or ownership records. The corporation lists separate links for self-assessment, revision petitions, mutation, vacancy remission and proceedings.

# Mysuru ward options in the municipal service directory

## Reading the ward selector

The corporation's Ward Information page lists consecutive numeric labels from 1 to 65. After 65 it displays a text label, `vijayanagar-3rd stage`. This last entry has form value 66, but the public label is a locality, not “Ward 66”. The [trade licence search](https://mysurucitycorporation.co.in/WebSiteMysuru/TradeLicence.aspx) uses the same sequence. Its other search fields are licence ID, licence number, firm name, applicant name and PID.

| Displayed option | Meaning in this record |
| --- | --- |
| 1 to 65 | Numeric choices shown to a portal user |
| vijayanagar-3rd stage | Separate named choice after 65 |

These are service lookup values. The page supplies neither a gazette reference nor a street-by-street boundary schedule. A property or licence search for the separately listed locality should use the label as printed.

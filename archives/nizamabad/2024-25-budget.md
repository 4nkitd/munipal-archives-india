# Nizamabad municipal budget estimates for 2024–25

## What the budget compares

The corporation's [budget register](https://nizamabadcorporation.telangana.gov.in/095/budgets) lists five financial years, 2020–21 through 2024–25. The 2024–25 budget compares actuals for 2022–23, the original 2023–24 budget, 2023–24 actuals as of 31 January 2024, revised estimates for 2023–24 and the 2024–25 budget. The table below uses only the last column. The financial year is not the publication date.

| Income item | 2024–25 estimate, ₹ lakh |
| --- | ---: |
| Taxes | 4,815.00 |
| Non-tax resources | 4,194.90 |
| Municipal own revenue, tax and non-tax | 9,009.90 |
| Deposits and loans | 720.00 |
| Capital Project Fund grants | 17,759.68 |
| Grand total income | 27,489.58 |

## Expenditure estimates

| Expenditure item | 2024–25 estimate, ₹ lakh |
| --- | ---: |
| Municipal General Fund, charged, maintenance and capital | 8,997.50 |
| Deposits and loans | 660.00 |
| Capital Project Funds | 17,666.70 |
| Grand total expenditure | 27,324.20 |

The expenditure abstract includes ₹3,260.00 lakh for wages and salaries and ₹1,160.00 lakh for ward-wise works. The second figure is a citywide budget heading, not a ward-by-ward allocation. See PDF pages 1–2 for the income abstract and pages 14–16 for the expenditure abstract.

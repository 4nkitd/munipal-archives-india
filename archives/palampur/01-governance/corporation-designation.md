# Palampur municipal corporation designation

## State roster

Annexure A lists Palampur under Kangra district at serial number 18. The roster is expressly as of 31 March 2026. That is the roster's reference date, not its publication date.

| Field | State roster entry |
| --- | --- |
| Local body type | Municipal corporation |
| Year of existence | 1953 |
| Corporation upgrade date | 28 October 2020 |
| Area | 31.58 km² |
| Population column labelled 2011 | 40,385 |

## District directory

The [Kangra district directory entry](https://hpkangra.nic.in/public-utility/municipal-council-palampur-2/) identifies the local body as Municipal Corporation Palampur and lists the Municipal Commissioner as the office. The old `municipal-council` wording in the URL is not the designation shown on the page.

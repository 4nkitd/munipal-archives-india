# Palampur door-to-door garbage complaints

## Reporting and status

| Need | Where the corporation points residents |
| --- | --- |
| Report a garbage complaint | Use the WhatsApp link labelled "For Garbage Complaints" on the corporation homepage. |
| View the complaint register | Use the "Garbage Complaints" navigation link on the homepage. The register displays ward number, complaint, remark and status. |

The register includes complaints about missed collection and sweeping. Its displayed status values include "Resolve" and "Under Process". These are register labels, not a commitment to resolve a complaint within a stated period. No message was sent to test the reporting channel. This record does not reproduce complainant details.

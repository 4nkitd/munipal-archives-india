# Panvel property tax lookup and payment

## Locate the property account

The [corporation's Citizen Services menu](https://panvelcorporation.maharashtra.gov.in/) links this property tax portal. Quick Property Search offers three lookup options:

| Method | What the form asks for |
| --- | --- |
| UPIC | Unique Property Identification Code |
| Property number | Node, sector and property number |
| Mobile number | The mobile number linked to the property |

The portal lists payment, dues and bill download services. Use the link from the corporation's website and check the account details before paying. Mobile linking and application tracking are separate options on the portal.

## Water tax and office enquiries

Use the separate Water Tax entry in the corporation's Citizen Services menu for a water bill. For help reaching the municipal office, use the number on the [municipal contact page](https://panvelcorporation.maharashtra.gov.in/contact_us).

# PMC building permission submissions and citizen search

## Finding a proposal

Choose **Citizen Search** on the Building Plan Approval Management System. A project file number or temporary number can identify a proposal. Other search fields include the plot or survey number, street, applicant, architect and proposal date range. Ask the developer or architect for the file number if the street address is ambiguous. Check the stage shown: a commencement or plinth approval is different from an occupancy approval.

## Submitting plans

PMC says an architect can request building-related no-objection certificates through one common application form. The department provides PreDCR drawing tools and sample layouts, accepts digitally signed submissions and lists online payment for building permission charges. For a commencement application, its notice directs the applicant to enter excavation details for the royalty declaration linked to Mahakhanij.

# Finding a Raipur property-tax receipt

## Find the property

The [property search](https://mcraipur.in/) offers a search by ID and a zone, ward or owner search. For a payment already made, choose **Download Receipt**. On the receipt page enter the property UID and select **Search**.

## Read the result

The results table distinguishes the property ID from the receipt number. Each row has the ward number, amount, generation date, rebate, total collected and a download column. Use the receipt number and generation date to distinguish payments on the same property.

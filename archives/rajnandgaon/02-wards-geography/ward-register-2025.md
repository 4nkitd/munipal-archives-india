# Rajnandgaon ward numbers in the 2025 councillor return

## Finding the corporation in the statewide return

Serial entries 2579 to 2629 cover Rajnandgaon. The serial number identifies a row in the statewide publication; the ward number starts again at 1 for this corporation and runs through 51. The [City Finance register](https://www.cityfinance.in/api/v1/ulb) identifies the same body by LGD code 250629, Census code 801991 and a 2011 Census population of 163,114.

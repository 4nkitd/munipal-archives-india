# Rajnandgaon mayoral election result, 2025

## Corporation-wide vote

The commission marks Madhusudan Yadav of the Bharatiya Janata Party as elected for Rajnandgaon Municipal Corporation. The return lists 11 candidates and a separate entry for none of the above (NOTA).

| Result | Votes |
| --- | ---: |
| Elected candidate | 68,551 |
| Next-highest candidate | 24,096 |
| Difference | 44,455 |
| NOTA | 784 |

The difference is calculated from the two candidate totals. For a councillor result, use the separate ward return in the [2025 election catalogue](https://cgsec.gov.in/hin_2025chunavnagarpalika.html).

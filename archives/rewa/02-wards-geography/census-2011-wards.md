# Rewa corporation wards in Census 2011

## Historical corporation inventory

The Census of India Population Finder returns 45 ward rows for **Rewa (M Corp.)**, one for each number from **1 through 45**. In the 2011 data, the town code is **802189**, the district code is **430**, and the subdistrict is Huzur, code **3479**. The row names are numbered census labels, such as `Rewa (M Corp.) WARD NO.-0045`, not names of localities. The 45 rows sum to 45,275 households and 235,654 residents, matching the Census municipal corporation town row.

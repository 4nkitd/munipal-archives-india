# Satna corporation wards and railway outgrowth in Census 2011

## Corporation and outgrowth are different rows

The Census of India Population Finder records **Satna (M Corp.)** in Raghurajnagar subdistrict, with town code **802170**, district code **429**, and subdistrict code **3461**. Corporation wards are numbered **1 through 45**. These rows sum to 54,699 households and 280,222 residents.

The search also returns `Satna Rly. Colony (OG) WARD NO.-0046 (Rural MDDS CODE:463141)`, with 680 households and 2,755 residents. The source explicitly marks this row as an **outgrowth**, not as one of the 45 corporation wards. It accounts for the difference between the corporation-only total and the Census [Satna (M Corp. + OG) town row](https://censusindia.gov.in/nada/index.php/api/tables/geosearch/2011?areaname=Satna&limit=50&level=town), which has 55,379 households and 282,977 residents.

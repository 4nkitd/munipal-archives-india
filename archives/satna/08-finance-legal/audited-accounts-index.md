# Satna Nagar Nigam in the state audited-accounts index

## Find the corporation row

The Madhya Pradesh Urban Development and Housing Department maintains separate audited-accounts index pages by fiscal year. On each page, the corporation appears under **रीवा** (division), **सतना** (district and ULB name) and **नगर निगम** (ULB Type). Rows for Nagod or Chitrakoot are for separate town bodies. The state index used these labels when checked:

The first two file names are identical but the links are in separate fiscal-year directories. Use the year page to distinguish them. The index does not give a date of publication for the entries. This record verifies the listing, not the attachment contents, audited balances, or any municipal budget.

# Singrauli corporation wards in Census 2011

## Numbered census wards

The Census of India Population Finder returns **45** rows for **Singrauli (M Corp.)**, numbered **1 through 45**. The census town code is **802426**, in Singrauli district code **463** and Singrauli subdistrict code **3705**. These are corporation rows, not figures for Singrauli district. The ward rows sum to 44,682 households and 220,257 residents, matching the corporation's Census 2011 town row.

The linked census query returns the complete list. The [MP State Election Commission programme index](https://mplocalelection.mp.gov.in/ElectionProgramM.aspx) separately names corporation ward 34 in a councillor by-election reservation entry dated 11 December 2025. The later notice verifies the electoral use of that number in 2025, but does not show that its boundaries matched the 2011 census unit. Neither source establishes current boundaries or the present council roster.

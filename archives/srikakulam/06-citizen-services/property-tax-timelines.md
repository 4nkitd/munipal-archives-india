# Srikakulam property tax applications and state processing times

## Choosing an application

The [city portal](https://srikakulam.cdma.ap.gov.in/) separates “Know Your Dues,” which looks up a demand, from “Self Assessment,” which opens a new assessment form. For a registered transfer of ownership, the city labels the link “Mutation.” A request to change an owner's details on an existing assessment is a separate entry in the state schedule.

| State property tax service | Published time |
| --- | ---: |
| Edit owner details or edit door number | 7 days |
| Transfer ownership, create an assessment or alter an assessment | 15 days |
| Bifurcate or amalgamate assessments | 15 days |
| Revision petition or general revision petition | 30 days |
| Tax exemption | 30 days |
| Vacancy remission | 180 days |

The [state service page](https://cdma.ap.gov.in/resources/service-sla) makes these timelines subject to complete documentation and fulfilment of the required conditions. The figures are service standards, not measured turnaround times for the Srikakulam office.

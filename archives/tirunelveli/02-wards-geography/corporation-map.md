# Tirunelveli corporation map and surrounding settlements

## Reading the municipal sheet

The corporation's Ward Map page links one [map image](https://www.tnurbantree.tn.gov.in/tirunelveli/wp-content/uploads/sites/107/2020/03/Corpn.-map.jpg). Its labels include Rajavallipuram, Gopalasamudram and Kilanatham (Rural). A direction marker points towards Ambasamudram. These labels help orient the reader; a place shown beyond the built-up city is not necessarily part of a corporation ward.

The page lists a separate “Master Plan and Use” document for planning geography. The ward map itself has no accompanying text table matching door numbers or streets to wards. Its image upload path contains March 2020, but the page gives no delimitation order or effective date. Use the map for geographic reference rather than proof of an address's electoral assignment.

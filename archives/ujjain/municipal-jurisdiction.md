# Ujjain Municipal Corporation: jurisdiction and office

## Which local body to contact

The district classifies Badnagar, Mahidpur, Nagda and Khachrod as Nagar Palikas. Unhel, Makdon and Tarana are Nagar Parishads. Each is a separate urban body. The [district administrative register](https://ujjain.nic.in/en/urban-local-bodies/) lists only Ujjain in its Municipal Corporation table.

## Corporation office

| Directory field | District entry |
|---|---|
| Office | Ujjain Municipal Corporation |
| Postal address | Kshtrapati Shivaji Bhavan, Agar Road, Ujjain City 456006 |
| Office email | nn.ujjain@mpurban.gov.in |

For a municipal record search, the [City Finance local-body register](https://www.cityfinance.in/api/v1/ulb) identifies this corporation by LGD code `250851` and Census town code `802230`. These identify the body across datasets; neither code identifies a particular ward or parcel.

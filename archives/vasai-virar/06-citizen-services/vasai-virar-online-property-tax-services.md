# Vasai Virar online property tax services

## Use the route that matches the request

| Task | Where to start |
| --- | --- |
| View or pay an existing bill | [Online Payment](https://onlinevvcmc.in/VVCMCOnlinePGProp/app/frmPropertyDetails.aspx) |
| Obtain a no-dues certificate or an assessment certificate | Choose the corresponding certificate link on the municipal service page; each opens a login. |
| Link multiple properties or change the mobile number | Use Property Mapping or Mobile Number Update on the service page. |
| Apply for self-assessment | [Self Assessment](https://ptaxcollection.onlinevvcmc.in/FrmCitizenLogin.aspx) |
| Look for ownership-transfer publications | Open the Property Mutation public notice board from the municipal service page. |

Payment, assessment and mutation are separate functions on the portal. The corporation also provides a [separate water tax portal](https://onlinevvcmc.in/VVCMCOnlinePGWater/) and a [complaint registration portal](https://onlinevvcmc.in/CRM/).

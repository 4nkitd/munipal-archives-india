# Vijayawada property-tax applications and proceedings

## Choose the transaction

On the [Vijayawada municipal portal](https://vijayawada.cdma.ap.gov.in/), open **Municipal Services**. The links lead to the Vijayawada eMunicipal property-tax system.

| What you need | Portal label |
| --- | --- |
| Estimate tax, without looking up an existing demand | Property Tax (calculator) |
| Look up an existing assessment and its dues | Know Your Dues |
| Declare a property for assessment | Self Assessment |
| Ask for an existing assessment to be reconsidered | Revision Petition |
| Apply to record a transfer | Mutation |
| Request relief for vacancy | Vacancy Remission |
| Retrieve proceedings issued on a case | Download Proceedings |

The [municipal taxation directory](http://www.ourvmc.org/tax/taxmenu.htm) also lists documents for title transfer, zonal rates, and separate searches for property tax and vacant-land tax. The tax calculator and the dues search answer different questions: the estimate is not evidence of an amount paid or of an order changing an assessment.

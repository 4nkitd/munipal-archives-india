# Property tax, NDC, Building Code 2017 and Lal Dora reference for Yamunanagar-Jagadhri

## Property tax source hierarchy

The corporation's [property tax page](https://www.mcynr.com/propertytax) describes residential, commercial, industrial, institutional and vacant properties within its jurisdiction as subject to property tax. Applicable exemptions must be checked separately. The page publishes both corporation and council or committee notifications. Yamunanagar-Jagadhri is a municipal corporation, so a council or committee schedule should not be substituted for the corporation instrument.

| Reference | Date or date context | Use |
| --- | --- | --- |
| Compendium of Instructions Property Tax | State index publication 2024-10-25 | Consolidated instructions and administrative procedures |
| Regarding Self-Certification of Property Information | 2024-03-27 | Verification of recorded property information |
| Property certificate for occupiers of Abadi Deh and Lal Dora properties in municipal areas | State index publication 2024-03-15 | Separate certificate policy for these areas |
| SOPs 8-11 on collector rates based on ULB colony codes | 2023-12-11 | Collector-rate and colony-code treatment |
| Removal of anomalies in development charges, agricultural properties, colony masters and Lal Dora data | State index publication 2023-10-28 | Correction of classifications and charges |
| Waiver of interest and rebate on arrears 2026-27 | Municipal title dated 2026-05-15 | Time-bound concession instrument |
| Exemptions, rebates, penalties and other property tax notification, corporations | Municipal title dated 2026-07-30 | Later corporation tax policy |

The state [property tax index](https://ulbharyana.gov.in/Home/PropertyTax) publishes the 2026 corporation notification on 31 July 2026. The municipal page writes its date as "07-30-2026". The frontmatter uses 30 July 2026 from that title. This archive does not reproduce unverified rates or assume that a historic rebate remains open. Consult the [corporation policy attachment](https://www.mcynr.com/sites/default/files/2026-08/Exemptions%2C%20Rebates%2C%20Penalties%20and%20other.pdf) and the current assessment before payment.

## Property ID, self-certification and NDC

The [official NDC portal FAQ](https://property.ulbharyana.gov.in/Home/FAQ) gives the following workflow:

1. Register using the applicant's name, father or husband name and mobile number, then verify the OTP.
2. Search the property after selecting the municipality. Search fields include colony, category, plot number, eight-character property ID, old ID, owner or occupier name and mobile number. A map search is also available.
3. Open "View Details" or "View Details/Self Certify". Check property details, mobile details, owner details and outstanding dues.
4. If information is wrong, select "No", update the relevant section and attach supporting records. Complete the final preview and submit the objection. Do not certify incorrect information.
5. After correction and verification, use "Make Payment/Generate NDC", search the PID and select "Pay All Dues and Generate NDC". Verify dues and complete the portal's payment and OTP steps.

The portal distinguishes property and fire tax, development charges and garbage collection charges. Paying only one category is not the same as clearing all dues.

The [8 July 2024 objection manual](https://property.ulbharyana.gov.in/Content/UserManuals/Verify_Property_Details_and_Submit_Objection_08.07.2024.pdf) states that normal objections have no fee and a resolution time of 10 working days. It lists Tatkaal objections at Rs 2,500 with two working days. These are the manual's published service terms, not a guarantee that a particular application has been accepted or resolved. The [manual index](https://property.ulbharyana.gov.in/Home/UserManuals) is the route for later revisions.

The department's 27 March 2024 self-certification instructions explicitly state that property tax information is not ownership proof. A tax PID or NDC must not be represented as a title deed or building sanction.

## Haryana Building Code 2017

The [official Haryana Building Code 2017 text](https://investharyana.in/content/pdfs/The-Haryana-Building-Code-2017.pdf) identifies the original publication as 30 June 2016 and its first revision as 6 January 2017. The ULB [town planning notifications index](https://www.ulbharyana.gov.in/Home/TownPlanningNotifications) separately lists the final 2017 code and adoption of amendments. Its 4 January 2021 index dates are not the original enactment dates.

Useful provisions in the linked 2017 edition include:

| Provision | Subject |
| --- | --- |
| Definition of core area | Includes thickly built-up old town areas and Lal Dora or phirni of villages included in municipalities |
| Code 2.1 | Building application with ownership documents, site and building plans, specifications, structural records and applicable safety or service plans |
| Code 6.1 | Site use and building character must conform to the applicable development, layout, sector or zoning plan |
| Code 6.2 | Plot subdivision in core areas requires prior competent-authority approval and independent public-road access |
| Code 6.3 | Coverage and FAR depend on the applicable plot and area category |

Use the code with later amendments and the site's approved zoning controls. No universal FAR, setback or fee is asserted here for Yamunanagar plots.

## Lal Dora and Abadi Deh records

The corporation publishes the [property certificate instructions](https://www.mcynr.com/sites/default/files/2025-10/Property%20Certificate%20to%20the%20occupiers%20of%20the%20properties%20falling%20under%20the%20Abadi%20Deh%20and%20Lal%20Dora%20of%20Municipal%20Areas.pdf) alongside the tax compendium and anomaly-correction instructions. These are separate from building permission. Neither the index title nor a Lal Dora colony label establishes that every use is tax-exempt or that construction needs no approval.

The [municipal wards list](https://www.mcynr.com/wards) distinguishes Lal Dora properties from "Abadi Outside Laldora" entries. The boundary and recorded classification therefore matter when seeking a certificate or correcting development charges. Check the individual PID, municipal or earlier panchayat records, and the relevant boundary evidence rather than relying on the village name alone.

The [building plans page](https://www.mcynr.com/building-plans) labels one download "Building Plan Approval Approved" with subtitle "Lal Dora Properties", but the linked filename is `19-06-2024-Anti-ragging-committee.pdf`. This mismatch prevents treating that listing as verified building approval guidance. Obtain the correct document from the corporation and use the state building code references in the meantime.
